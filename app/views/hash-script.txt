To create login credentials for your new Express/Node.js system, you need to insert a record into your MySQL admin_users table with a password hashed using the Argon2id algorithm.

Since your schema.sql and server.js are configured for Argon2id, you cannot simply type a plain-text password into the database.

Step 1: Generate the Argon2id Hash
You can generate a compatible hash using a temporary Node.js script. Create a file named hash.js and paste the following:

JavaScript
const argon2 = require('argon2');

async function generateHash(password) {
    try {
        // Generates a hash compatible with your server.js settings
        const hash = await argon2.hash(password, {
            type: argon2.argon2id,
            memoryCost: 65536,
            timeCost: 4,
            parallelism: 1
        });
        console.log("Your Secure Hash:");
        console.log(hash);
    } catch (err) {
        console.error(err);
    }
}

// Replace 'YourStrongPasswordHere' with the password you want to use
generateHash('YourStrongPasswordHere');
Run this in your terminal using node hash.js. It will output a string starting with $argon2id$....

Step 2: Insert into the Database
Once you have the hash, use a SQL client (like MySQL Workbench, phpMyAdmin, or the command line) to run the following query, replacing <HASH> with the string you generated in Step 1:

SQL
INSERT INTO admin_users (username, password_hash) 
VALUES ('admin', '<HASH>');
Step 3: Verify the Credentials
Start your server: Run node server.js.

Navigate to login: Open http://localhost:3000/login in your browser.

Enter details: Use the username (admin) and the plain-text password you chose in Step 1.

Login Flow:

The server will fetch the user from the admin_users table.

argon2.verify will compare your plain-text password against the stored hash.

If successful, req.session.user_id is set, and you are redirected to /resource-centre.

The database will automatically update the last_login column for that user.
